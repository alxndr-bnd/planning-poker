Privacy

Last updated: 27 September 2026

In short: no accounts, no ads, nothing sold. What you type into a room lives only in the server's memory and is gone within minutes after everyone leaves. We count visits with Google Analytics, which sets cookies only if you accept them in the banner, and Cloudflare Web Analytics, which sets none; the server reports its own errors to Sentry.

Serbito Planning Poker (poker.serbito.rs) is an open-source project run by Alexander Bondarchuk. The code is public, so you can check everything below on GitHub. Questions or requests: alexander.bondarchuk@gmail.com.

What you enter in a room

  • Your display name (up to 40 characters), your votes, whether you joined as an observer, and the results of the rounds your room revealed.
  • These go to our server so the other people in the room can see them. Anyone with the room link can join, so the link is the key: share it only with your team.
  • The server keeps them in memory only. There is no database, and nothing is written to disk.
  • A participant who disconnects is removed after about 2 minutes; a room is deleted a few minutes after its last participant leaves. Every server restart or update clears all rooms.

What stays in your browser

The app itself sets no cookies. It keeps a few small values in your browser's storage:

  • localStorage: your last display name (pp_name), language (pp_lang), the "copy link on create" setting (pp_copy_on_create), the interface version (pp_ui_v2) and your cookie choice with its date (pp_consent, see below).
  • sessionStorage, cleared when you close the tab: a random tab id (pp_client_id) sent with your name when you join, so a dropped connection gets your vote back; and a one-time "link copied" flag per room (pp_link_copied).

You can delete them at any time in your browser's site settings.

Server logs

Our server logs only its start-up and its errors, never individual requests. Google Cloud Run, which hosts it, keeps standard request logs (time, path, status, IP address, browser) in Google Cloud Logging for 30 days. The room id sits after # in the link, and browsers never send that part to a server, so it doesn't appear in these logs.

Google Analytics

Every page loads Google Analytics 4 (property G-B5CQC4JJV0) so we can see how many people use the site and whether rooms work. It receives:

  • Page views. Every room is reported as the same page, /room: room links are never sent.
  • Four events: room_created, room_joined, vote_cast (with the card value) and round_revealed.
  • The events Google Analytics collects by itself, such as first_visit, session_start, user_engagement and scroll.
  • What any web request carries: your IP address (Google uses it for an approximate location and, by its own account, doesn't store it), browser, device, screen size and the page you came from.

Names and room links are never sent. If you accept cookies, Google Analytics sets two cookies holding a random id: _ga and _ga_B5CQC4JJV0, each for up to 2 years. They are set for poker.serbito.rs only, not shared with other serbito.rs sites. Event data is kept for at most 14 months. Blocking Google Analytics, with a content blocker or Google's opt-out add-on, doesn't break anything.

Cookies and your choice

The first time you visit, a small banner at the bottom of the page asks whether Google Analytics may use cookies. We ask everyone, wherever you are.

  • Until you answer, and if you decline, Google Analytics runs in consent mode: it sets and reads no cookies. It still sends cookieless pings for the page views and events listed above, without a client id, so a visit can't be linked to earlier ones; Google Analytics uses them for aggregate and modeled counts. Like any request, a ping carries your IP address and browser.
  • If you accept, Google Analytics sets its _ga cookies as described above. Only analytics is enabled: advertising signals stay off.
  • Your answer and its date are kept in your browser (pp_consent), so the banner doesn't return on every page. After 12 months we ask again.
  • You can change your mind at any time with Cookie settings, also in the footer of every page. Declining deletes the _ga cookies, including any left on serbito.rs by an earlier version of this site.

Cloudflare Web Analytics isn't covered by the banner: it sets no cookies and stores nothing in your browser.

Cloudflare

The site is served through Cloudflare, which handles DNS, TLS and delivery, so every request passes through its network. Cloudflare Web Analytics counts page views and page-load speed without cookies and without storing anything in your browser.

Sentry (server errors)

When the server hits an error, it sends a report to Sentry: the error message, the stack trace, the app version and the environment. Sentry also receives timing data for about 10% of requests (path, status, duration). It is configured not to collect IP addresses, cookies, headers, request bodies, query strings or variable values from the code, so names and votes stay out of it. Sentry deletes the data after its retention period (at most 90 days). The app in your browser sends nothing to Sentry.

GitHub badge

The app's lobby and rooms show a GitHub star badge, an image loaded from shields.io. Like any image request, it lets shields.io see your IP address and browser.
