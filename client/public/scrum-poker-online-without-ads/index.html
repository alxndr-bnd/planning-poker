Scrum Poker Online Without Ads

As of October 2026. Facts about other tools were checked on 2026-10-05 on each vendor's own website.

Many free scrum poker tools pay for their servers with ads. That is a fair model. But in an estimation meeting, the room is often on a shared screen, and the ads go to everybody on the call. Serbito Planning Poker has no ads and no paid plan. You type a name, share the link and vote.

Why ads get in the way during estimation

  • Shared screens. When the facilitator shares the room, every ad goes to the team, and sometimes to a client.
  • Attention. A moving banner competes with the story that the team must understand.
  • Page weight. Ad networks load extra scripts, so the room loads more slowly on a weak connection.

Both ad-funded tools are free to start and need no sign-up. Premium on scrumpoker-online.org also adds a voting timer, automatic average and median, a personal room ID and an attendance indicator. If you need those, the fee can be worth it.

How this tool stays free without ads

Alexander Bondarchuk builds and runs Serbito Planning Poker. The server is one small container that scales to zero when nobody plays, so hosting costs little. There are no accounts and no database: rooms live in server memory and are deleted soon after everyone leaves.

No ads does not mean no analytics. The site counts visits with Google Analytics, which sets cookies only after you accept the banner, and with cookieless Cloudflare Web Analytics. The server reports its errors to Sentry. Names and room ids are never sent. The privacy page has the details. A copy that you host yourself has none of these unless you turn them on.

What you get

  • A room by link: people type a name and join, with no account.
  • Hidden votes until the reveal. Each round, one random voter holds the star and reveals.
  • Each name with its card, a count per card and a consensus mark.
  • An observer mode for people who watch but do not vote.
  • An item title for each round, and an estimate log of the revealed rounds with their titles while the room is open.
  • 9 interface languages and an MIT license.

What you do not get

The tool has the Fibonacci deck only, and it has no timer, no average or median, no export and no saved rooms. Custom decks, export and saved rooms are open for votes on GitHub.

Questions

Is there really no catch?

There are no ads and no paid plan. The site uses analytics, as described above, and the code is public, so you can check it.

Do players need an account?

No. Everybody opens the room link, types a name and joins.

Can we use T-shirt sizes?

Not yet. The deck is Fibonacci only. Custom decks are a feature vote on GitHub.
